        JSON format guide

        Word set files are ordinary JSON documents. Three shapes are accepted, plus a plain-text fallback. Files should be UTF‑8 encoded.

        1. Array of objects (recommended)

        A JSON array where each element is one word. Use term for the word and definition for its meaning:

        [
  { "term": "Marbury v. Madison", "definition": "Established judicial review" },
  { "term": "Federalism",         "definition": "Power shared between national and state governments" }
]

        These alternative key names are recognized too, so exports from many flashcard tools work out of the box:

        • Term side: term, word, front, name
        • Definition side: definition, def, meaning, description, back, formula
        [{ "front": "Hola", "back": "Hello" }]   ✅ works

        2. Object mapping

        A simple object whose keys are the terms and values are the definitions:

        {
  "Photosynthesis": "Converts light into chemical energy",
  "Osmosis": "Water moves across a membrane"
}

        3. Array of pairs

        An array of two-element arrays, first the term then the definition:

        [
  ["Hola", "Hello"],
  ["Adiós", "Goodbye"]
]

        Plain text fallback (TSV)

        If the pasted text or uploaded .txt/.csv file isn't valid JSON, it is parsed as tab-separated lines: one word per line, term and definition separated by a Tab character (the format Quizlet's "Export" produces):

        Hola⇥Hello
Adiós⇥Goodbye

        Parsing rules

        • Each entry must have a non-empty term; entries without one are skipped.
        • Definitions are optional — an empty definition is kept and can be filled in later (definitions are editable right in the list view).
        • Duplicate terms are allowed but discouraged.
        • When a value is missing both sides entirely the importer reports how many rows were skipped instead of failing the whole file.
        • Keep files under ~2 MB; sets are stored in your browser's localStorage (roughly 5 MB budget, shared with your study progress).

        Where sets are saved

        Custom sets live in your browser's local storage on this device, together with your priorities, stars, edited definitions and Learn history. They are not uploaded anywhere. To move a set to another device or share it, use Export on its card and import the downloaded JSON elsewhere.

        Minimal copy-paste example

        [
  { "term": "Example term", "definition": "Example definition" },
  { "term": "Second term", "definition": "Second definition" }
]
